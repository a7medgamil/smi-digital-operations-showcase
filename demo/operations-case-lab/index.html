Roles & permissions

Learner: submit, replay, add fixed evidence to needs-info cases.
Staff: read queue and metrics, start review, decide.

Permissions run in the pure domain engine. The browser owns this simulation; these roles provide no authentication or security boundary.

Status map

Submitted → Under review
Under review → Approved / Needs info / Rejected
Needs info → Submitted (learner response)

Approved and rejected are terminal. Decisions use a captured version; stale decisions fail without a partial write.
